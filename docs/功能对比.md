### 第一次改进：记忆管理核心

```python
# agent/memory_manager.py 核心逻辑

class ConversationMemory:
    """单个会话的记忆管理"""
    
    def __init__(self, max_rounds=5, max_tokens=4000):
        self.short_term = []    # 短期记忆（最近N轮）
        self.long_term = {}     # 长期记忆（关键信息）
        self.max_rounds = max_rounds
        self.max_tokens = max_tokens
    
    def add_message(self, role, content):
        """添加消息到短期记忆"""
        self.short_term.append({"role": role, "content": content})
        self._trim_if_needed()  # 自动裁剪
    
    def get_context(self):
        """获取对话上下文"""
        return self.short_term.copy()
```

**集成到ReactAgent**:
```python
# agent/react_agent.py

class ReactAgent:
    def __init__(self, session_id="default"):
        self.memory = MemoryManager.get_memory(session_id)
    
    def run(self, query):
        # 1. 加载记忆上下文
        context = self.memory.get_context()
        
        # 2. 添加当前问题
        self.memory.add_message("user", query)
        
        # 3. 执行Agent逻辑
        response = self._execute_with_context(context)
        
        # 4. 保存回答到记忆
        self.memory.add_message("assistant", response)
        
        return response
```

### 第二次改进：监控系统核心

```python
# agent/tools/monitor_enhanced.py 核心逻辑

class ToolMetrics:
    """工具调用指标收集"""
    
    def __init__(self):
        self.stats = {}         # 各工具统计
        self.recent_calls = []  # 最近调用记录
    
    def record_call(self, tool_name, duration, success, error=None):
        """记录一次调用"""
        if tool_name not in self.stats:
            self.stats[tool_name] = {
                "call_count": 0,
                "failure_count": 0,
                "total_duration": 0.0
            }
        
        stat = self.stats[tool_name]
        stat["call_count"] += 1
        stat["total_duration"] += duration
        
        if not success:
            stat["failure_count"] += 1
        
        # 记录到最近调用列表
        self.recent_calls.append({
            "tool_name": tool_name,
            "duration": duration,
            "success": success,
            "error": error
        })

def monitor_tool_enhanced(tool_func):
    """增强版监控装饰器"""
    
    def wrapper(*args, **kwargs):
        trace_id = _generate_trace_id()  # 链路追踪ID
        start_time = time.time()
        
        logger.info(f"[{trace_id}] 调用工具: {tool_func.__name__}")
        
        # 自动重试逻辑
        for attempt in range(MonitorConfig.max_retries + 1):
            try:
                result = tool_func(*args, **kwargs)
                duration = time.time() - start_time
                
                # 记录成功指标
                get_metrics().record_call(
                    tool_func.__name__, 
                    duration, 
                    success=True
                )
                
                # 耗时告警
                if duration > MonitorConfig.slow_threshold:
                    logger.warning(f"[{trace_id}] 慢调用: {duration:.2f}秒")
                
                return result
                
            except Exception as e:
                if attempt < MonitorConfig.max_retries:
                    logger.warning(f"[{trace_id}] 重试 {attempt+1}/{MonitorConfig.max_retries}")
                    time.sleep(MonitorConfig.retry_delay)
                else:
                    # 记录失败指标
                    get_metrics().record_call(
                        tool_func.__name__,
                        time.time() - start_time,
                        success=False,
                        error=str(e)
                    )
                    raise
    
    return wrapper
```

## 🎯 应用场景对比

### 场景1：多轮对话

**没有记忆系统**:
```
用户: 我的扫地机器人不能充电
Agent: [查询] 充电器可能损坏，建议更换

用户: 刚才你说的充电器在哪买?
Agent: [❌] 您想买什么充电器?  # 没有上下文
```

**有记忆系统**:
```
用户: 我的扫地机器人不能充电
Agent: [查询+记忆] 充电器可能损坏，建议更换

用户: 刚才你说的充电器在哪买?
Agent: [✅ 从记忆加载] 扫地机器人充电器可在官网购买...
```

### 场景2：工具调用失败

**没有监控系统**:
```
工具调用: get_weather()
  → 失败 (网络超时)
  → 直接报错给用户
  → ❌ 无法追踪问题原因
  → ❌ 无法统计失败率
```

**有监控系统**:
```
工具调用: get_weather()
  → [trace_id: abc12345] 记录开始
  → 第1次失败 (网络超时)
  → 自动重试 (延迟1秒)
  → 第2次成功 ✓
  → 记录耗时: 2.5秒
  → 更新成功率: 88% → 89%
  → ✅ 用户无感知
  → ✅ 开发者可追踪
```
